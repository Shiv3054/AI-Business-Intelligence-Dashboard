# AI-Based Business Intelligence Dashboard (Case Study 35)

Educational prototype using synthetic multinational retail sales data. Integrates country/category sales, plots revenue trends, detects unusual transactions using Isolation Forest, and generates simple management insights.

## Run
Open `bi_dashboard.py` in Google Colab and execute it, or run locally after installing `pandas numpy matplotlib scikit-learn`.

## Limitations
Uses synthetic data; anomaly flags are not proof of fraud; explainability is basic and production data integration is not implemented.
